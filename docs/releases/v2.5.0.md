# octl 2.5.0

Runner logs are readable in terminals. `octl logs` and `octl rollout logs`
display Runner and Terraform/OpenTofu messages with compact metadata and
syntax highlighting for remaining JSON fields. Unknown fields and malformed
or partial records remain visible.

Pipes retain the original bytes by default. Use `--pretty` for readable
redirected output or `--raw` for the original content. Explicit rollout
`--out` output and encrypted ordinary log responses retain their existing
behavior. `NO_COLOR` and `TERM=dumb` disable generated colors while keeping
readable text. Human output escapes untrusted terminal controls; raw output
preserves those bytes intentionally.

Log decryption, key custody, authentication and protected material access are
unchanged. These flags affect presentation after decryption. No new dependency,
API operation or plugin package is required.
