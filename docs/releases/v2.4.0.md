# octl 2.4.0

Provider deletion now accepts the Control Plane's asynchronous `202 Accepted`
response. The CLI reports that deletion was requested while Provider
configuration remains available for managed-resource cleanup and in-flight
operations. Provider tables show `DeletionRequestedAt`; confirmed immediate
removal continues to return `204 No Content`.

This is an API client change for the coordinated Provider-retirement release.
It does not force removal, discard Provider credentials early or create a second
cleanup mechanism. Use the compatible published Control Plane API; existing
read-only MCP commands and ordinary authentication remain available.

Release tooling and binary qualification require Go 1.26.11.
