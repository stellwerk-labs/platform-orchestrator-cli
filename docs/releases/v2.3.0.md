# octl v2.3.0

## Read-only MCP metadata

Adds `octl mcp serve`, a local stdio-only MCP server using the official Go SDK
v1.8.0. Eight allowlisted tools expose curated project, environment, module,
version and Resource Type metadata through the existing authenticated API.
Tools require explicit organization scope and exclude configuration, source,
state, credentials and output values. See [the MCP guide](../mcp.md).

Start it with `octl mcp serve` from your MCP client's server configuration.
It uses the existing CLI configuration and requires a Bearer token, including
for local development. Every tool call supplies its organization explicitly.
The server opens no HTTP listener and starts only when this command is run.

## Compatibility

The Module authoring and testing commands released in v2.2.0 remain available.
MCP uses the existing server APIs; this CLI release does not require another
Core, provider or Helm release. Server-side permissions still determine what
the configured token can read.

CLI errors now consistently use standard error, preserving JSON-RPC-only
standard output for MCP clients. Scripts that previously captured startup error
text from standard output should capture standard error instead.

## Security

Pins the effective transitive Brotli build/tool module graph to v1.2.7
to address GHSA-c9gr-gmg4-2vqv. Brotli is absent from the CLI executable and runtime
package dependencies.
