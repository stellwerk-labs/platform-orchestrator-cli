# octl v2.0.0

This is a breaking CLI release for Module Version Management.
Use it with the compatible Orchestrator server API.

## What changes

- Create catalogue entries and complete immutable SemVer versions; publish first,
  then promote explicitly.
- Inspect version history, concrete comparisons, adoption and Environment Pins.
- Perform reasoned lifecycle actions with an Idempotency Key and expected resource
  revision.
- Preview and apply frozen bulk Pin operations, append notes and manage Pins
  within the caller's current scope.
- Archive or unarchive immutable Resource Types instead of editing their contract.

## Update scripts before upgrading

Existing mutable Module authoring and Resource Type update scripts need migration.
Module compatibility commands publish Proposed versions, not mutable Defaults.
Lifecycle calls require their action, reason and expected revision; refresh state
after conflicts instead of silently overwriting another caller's decision.

Provide complete version definitions and required output declarations. External
sources need exact revisions. Digests are optional; omit unknown or inline-source
digests. A digest is not trusted verification.

See [Module Management commands](https://github.com/stellwerk-labs/platform-orchestrator-cli/blob/v2.0.0/docs/module-management.md) for publish, promote,
compare, Pin and migration examples. Preserve state and history during teardown;
archival is not infrastructure destruction.

## Compatible release and channels

Use CP 3.0.0, DP 3.2.0 and IAM 2.4.0.
The API specifications embedded in this CLI must match the reviewed server
contracts. Do not infer compatibility from a successful older-client invocation.

This release publishes signed binaries, container tag
`ghcr.io/stellwerk-labs/octl:2.0.0`, stable image aliases, and Homebrew/Scoop updates.

The optional update notification now compares semantic versions and reads the
GitHub release tag, not its display title. It no longer recommends an older
stable version to users running a newer release candidate or local build.
