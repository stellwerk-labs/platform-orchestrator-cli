# Orchestrator CLI (octl) v2.1.1

This maintenance release updates the Go toolchain, dependencies and generated
clients. Commands and API wire values retain their v2.1.0 behaviour.

## Security and compatibility

Official builds use Go 1.26.10, including the certificate verification fix for
[CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809). Cryptography, OpenAPI
and supporting dependencies are updated. Generated clients use the corrected
server contracts. Query parameter order may change; names and values do not.
Normal CI checks source dependencies and release payloads for reachable known
vulnerabilities.

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Exact published server source pins are verified
before client publication. The API changes preserve existing wire contracts.

## Upgrade and distribution

Select octl 2.1.1 from the signed binary releases, container image, Homebrew or
Scoop. Verify availability and signatures for the channel you use. Back up CLI
configuration and credentials before upgrading. This patch changes neither
configuration format nor server database schema; the v2.1.0 secret-output and
deployment-queue guidance continues to apply.

This release does not update the Runner's bundled OpenTofu, the plugin runtime
or external services. Those separate security holds are not cleared by this
client update.
